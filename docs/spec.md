# DART-QoE 제품 명세

## 제품 개요

- UI·UX 적용 여부: 적용 / 화면 있음
- 목적: DART 재무제표와 사업보고서 주석을 이용해 이익의 지속성, 현금전환, 운전자본, 순차입금을 빠르게 검토하고 계산 근거가 포함된 Excel을 만든다.
- 주요 사용자: M&A·재무자문 직무 지원자, 거래 검토자, 공시 기반 기업분석을 수행하는 사용자
- 사용 상황: 상장 제조업 기업의 최근 여러 사업연도를 비교하고, 정상화 영업이익 후보와 원문 근거를 검토할 때 사용한다.

## 첫 버전 기능

1. DART 인증키를 Windows 계정으로 암호화해 선택적으로 저장
2. 회사명 또는 종목코드와 분석기간 입력
3. 연결재무제표 우선 조회와 사업보고서 주석 수집
4. 보고이익·현금전환·운전자본·순차입금 분석
5. 강한 일회성 손익 후보 탐지와 정상화 영업이익 계산
6. 화면 결과 요약과 검토 포인트 표시
7. 원천 자료·산식·원문 링크·검증 흔적이 포함된 Excel 생성
8. 생성된 Excel 또는 저장 폴더 열기

## 제외 범위

- 자동 기업가치 평가 또는 투자 결론
- 실제 거래실사 결과를 대체하는 판단
- 모든 업종과 모든 공시 형식의 완전 자동 처리
- EBITDA 기반 정상화와 순차입금/EBITDA 배수
- 재고평가손실·대손·보증충당부채처럼 반복 가능성이 높은 항목의 자동 일회성 처리

## 입력과 출력

### 입력

- 전자공시 인증키
- 회사명 또는 종목코드
- 분석 시작연도와 종료연도
- 순차입금 계산 시 리스부채 포함 여부

### 출력

- 화면: 분석 상태, 핵심 지표, 추가 확인 포인트, 생성 파일 위치
- Excel: QoE 요약, 정상화 손익, 운전자본, 순차입금, 검토 후보, 원천 자료, 검토 흔적, 검증

## 주요 사용 흐름

1. 인증키와 회사를 입력한다.
2. 분석기간과 리스부채 포함 여부를 확인한다.
3. `공시 분석 및 Excel 만들기`를 실행한다.
4. 실제 진행률과 현재 작업 단계를 확인한다.
5. 화면에서 핵심 결과와 추가 검토 사항을 확인한다.
6. Excel을 열어 후보 금액, 원문, 조정 여부와 계산식을 검토한다.

## 오류 상황과 동작

- 필수 입력 누락: 입력값을 유지하고 해당 카드 안에 해결 방법을 표시한다.
- 시작연도 > 종료연도: 기간 입력을 유지하고 올바른 순서를 안내한다.
- 인증키 오류 또는 DART 조회 실패: 화면 결과 영역에 문제와 재시도 방법을 표시하고 오류 로그를 남긴다.
- 일부 연도 자료 누락: 가능한 연도는 계속 처리하고 Excel 검증 시트에 제한사항을 남긴다.
- Excel 생성 실패: 분석 결과를 잃지 않도록 오류 원인을 기록하고 재실행 방법을 표시한다.

## 완료 기준

- 1280×720 논리 픽셀 이상에서 핵심 입력과 실행 버튼이 잘리지 않는다. Windows 표시 배율에 따라 실제 픽셀 크기는 달라진다.
- 좁은 창에서는 분석 조건과 결과 카드가 자연스러운 순서로 세로 배치된다.
- 키보드만으로 주요 입력과 실행이 가능하며 포커스가 보인다.
- 준비·분석 중·완료·오류 상태가 서로 명확히 구분된다.
- 입력 오류 후 기존 입력값이 유지된다.
- 정상화 영업이익이 후보 조정 수식과 연결되고 검증 시트와 일치한다.
- 전체 자동화 테스트, Excel 수식 오류 검사, 주요 화면 검증을 통과한다.

## 제약과 가정

- Windows 11과 PowerShell 환경을 기준으로 한다.
- DART Open API와 사업보고서 HTML 구조가 변경되면 추출 로직 수정이 필요할 수 있다.
- 사용자는 자동 탐지 후보를 원문과 함께 검토해야 한다.
- 인증키는 저장을 선택한 경우에만 현재 Windows 계정으로 복호화할 수 있게 저장한다.

## 미결정 사항

- 업종별 계정 매핑 확장 범위
- EBITDA와 감가상각비 추출 방식
- 결과 파일 재열기·최근 분석 기록 기능
