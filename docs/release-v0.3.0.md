# DART-QoE v0.3.0

Windows 데스크톱 화면의 입력과 결과 확인 흐름을 개선했습니다.

## 화면과 사용성

- 넓은 창은 좌우 2단, 좁은 창은 입력 → 결과 순서로 배치
- 공간이 부족하면 세로 스크롤로 모든 정보에 접근
- 필수 입력과 기간 오류를 카드 안에서 안내하고 입력값 유지
- 한글 입력칸에서 Tab·Shift+Tab 이동과 Enter 실행 지원
- 로고·서명 영역을 줄이고 결과 요약에 스크롤바 추가
- 준비·진행·완료·오류 상태의 안내와 파일 열기 버튼 문구 개선

## 분석과 검토 파일

- 작업 폴더에 있던 7개 일회성 후보 유형, 주석 기본 탐색, 리스부채 추출 개선을 통합
- 금액이 확인되지 않은 빈 후보 행을 만들지 않음
- 정상화 손익과 QoE 요약의 조정 반영 및 전체 제외 계산 검증
- 원문, 산식, 사용자 검토 흔적을 Excel에서 확인 가능
- 차트 미리보기 캐시를 실제 셀 값으로 채워 저장 직후에도 선과 축을 표시

## 실행

`DART-QoE.exe`를 내려받아 쓰기 가능한 폴더에서 실행하세요. Python 설치가 필요하지 않습니다. OpenDART 인증키와 회사명 또는 종목코드를 입력하면 같은 폴더의 `outputs`에 Excel이 저장됩니다.

## 검증

- Python 자동화 테스트 30개 통과
- 넓은 창과 좁은 창, 준비·오류·분석 중·완료 상태 검증
- Windows 네이티브 입력칸의 Tab·Enter 이벤트 처리 검증
- Excel 생성, 수식 오류 검사, 조정 선택 변경에 따른 재계산 검증
- 실제 인증키를 이용한 신규 기업의 네트워크 조회는 이번 검증에 포함하지 않음

자동 반영된 일회성 후보는 원문과 영업이익 포함 여부를 확인한 뒤 필요하면 제외하세요.
